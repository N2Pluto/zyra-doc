## จุดที่ต้องตัดสินใจหรือแก้ให้ตรง spec

### Required animation slots

โค้ดต้องการ 20 slots: Egg 2 + Baby/Adult/Evolved stage ละ 6 โดยเพิ่ม Idle

ยืนยันกับ PM/Design ว่าจะเก็บ Idle หรือยึด spec เดิม 17 slots; ปรับ FE/BE/เอกสารให้ใช้คำตอบเดียวกัน

### Animation metadata

หน้าเว็บส่ง fixed 50 frames, 24 fps, 4 direction rows และ select ถูก disabled

เปิดให้ตั้งค่าต่อ animation ตาม spec หรือปรับ spec ให้ยอมรับค่า fixed อย่างเป็นทางการ

### XP configuration vs XP earning

การตั้งค่าและ history พร้อม แต่ยังไม่มี consumer ที่อ่าน config เพื่อให้ XP จริง

ทำ XP engine หลังมี Room Pet ledger เพื่อหลีกเลี่ยง config ที่บันทึกได้แต่ไม่ส่งผลในระบบ

### Deployment readiness

เมนูถูก feature-flag แต่ API/Admin code อยู่ใน branch แล้ว; CI Go เคย fail จาก router wiring และแก้ใน working tree แล้ว

commit การแก้ CI แยกตาม workflow แล้วรัน test/build ก่อนเปิด flag

## เกณฑ์ก่อนเปิด Feature Flag

เปิด `NEXT_PUBLIC_PET` สำหรับผู้ใช้งานเมื่อทำครบ: Room Pet placement และการย้าย/ลบผ่าน Map Editor, realtime ข้ามผู้ใช้, XP ledger ที่กันการจ่ายซ้ำได้, render ตาม stage/mood, integration/UAT บน dev และ CI ผ่านทั้ง API กับ app

ระหว่างนี้สามารถใช้ Pet Management เพื่อเตรียม pet type, sprites และ XP config ในระดับ Admin ได้ แต่ไม่ควรสื่อว่า pet ทำงานใน Virtual Office แล้ว
