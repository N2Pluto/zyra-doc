ลองกดอะไรได้บ้าง

  • สลับ Day / Week / Month · ‹ › · Today · คลิกเลขวันใน Month หรือหัวคอลัมน์ใน Week = ไป Day view · คลิกวันใน Mini calendar = เลือกวัน (มีกรอบเขียว)
  • สร้าง meeting: คลิกช่องว่างในวันไหนก็ได้ (Month) หรือช่องเวลา (Week / Day, ตัดทุก 30 นาที) หรือปุ่ม + → ฟอร์ม Schedule event + chip "No title" ตรงช่องนั้น → Create
  • Guest: พิมพ์ชื่อหรืออีเมลเพื่อค้นหาสมาชิก workspace (↑ ↓ Enter ได้) → คนที่เลือกขึ้นเป็นวง (pill) · hover ที่วงแล้วมี X ท้ายชื่อให้กดเอาออก + Permission 3 ข้อ · ช่องค้นหาแบบเดียวกับ calendar-schedule-event.tsx ของจริง (ของจริงแสดงเป็นรายชื่อแถว — POC เปลี่ยนเป็นวงตามที่ขอ)
  • กด "3 More" ในวันที่ 20 → popup รายการทั้งหมด (AC-HP02-3)
  • กด event ใดก็ได้ (รวม Google / Outlook) → Event detail · ถ้า event อยู่ล่าง popup จะเปิดขึ้นด้านบน · ปิดด้วย X, Esc หรือคลิกข้างนอก
  • ใน Event detail ของ meeting ที่เราเป็นผู้จัด: ✏️ Edit → ฟอร์มเดิมกรอกค่าไว้ → Save · 📅✕ Cancel meeting → dialog ใส่เหตุผล (0/200) → Confirm (HP-05) · โหมด ClickUp มีปุ่ม "เลื่อน Meeting" (HP-06) และ attendee มี "ปฏิเสธเข้าร่วม" · ผู้จัด: Design sync 08:30, Quarterly planning 22 ก.ค., Sprint retro 31 ก.ค. หรือที่สร้างเอง
  • Calendar Integration (CAL-01): ไอคอน ⚙ ใน sidebar หรือปุ่ม "Go to setting" → Setting → Integrations · Connect → หน้าขออนุญาต (ภาพจำลอง) → Continue = เชื่อมสำเร็จ → push Zyra meeting ที่เราจัดไปปฏิทินนั้น → เปิดหน้า Choose calendars to sync (เลือกปฏิทิน · ค้นหาได้เมื่อมีเกิน 10 · ค่าเริ่มต้น = Primary) → Save · แก้ทีหลังได้ที่ลิงก์ "Syncing N calendars · Change" · Cancel = EP-01 · Disconnect → ยืนยัน → events ของ provider นั้นหายทันที · เชื่อม Google + Outlook พร้อมกันได้ · เปิด Setting ได้จากปุ่ม "Settings › Integrations" ในแถบควบคุมด้วย
  • สลับ สิทธิ์ของฉัน เป็น Workspace Admin = ยกเลิก/เลื่อน meeting ของคนอื่นได้ · Daily standup วันอังคาร = guest ที่ได้สิทธิ์ Modify (แก้ได้ ยกเลิกไม่ได้) · event จาก Google ที่เราเป็นผู้จัด (Design review 14 ก.ค.) มี 🗑/✏️ ที่พาไปแก้ที่ต้นทาง
  • EP-02: Google Calendar = "หมดอายุ" → banner เหลืองใน panel + ปุ่ม Reconnect ใน Setting · EP-03: ปุ่ม "Sync ล้มเหลว 3 ครั้ง" → banner → Sync now · ติ๊ก "จำลอง push ไป Google ล้มเหลว" เพื่อดู toast ตอนสร้าง/ยกเลิก/เลื่อน
  • ไอคอน Calendar / กระดิ่ง ใน sidebar · ปุ่มขยาย/ย่อ ใน panel
  • ปุ่ม ส่ง Meeting Alert ด้านบน → toast + badge + การ์ดใน Notification panel · กดซ้ำ = ถูก dedupe

Figma กับ ClickUp ต่างกันตรงไหน (สลับดูได้)

  • สี source: Figma ทุกอย่างเขียว #58D68D ไม่มี Google/Outlook · ClickUp Zyra #79DEA5 / Google #4285F4 / Outlook #0078D4 + legend ใต้ calendar
  • Popup: ClickUp เพิ่ม source badge, description, ลิงก์เปิดใน Google/Outlook, timezone ต้นทาง, "Join Now" เฉพาะตอนกำลังประชุม · Figma มี Trash/Edit + RSVP Yes/No/Maybe
  • Toast: Figma ข้อความอังกฤษ icon กล้อง + ปุ่ม Later · ClickUp ข้อความไทย 🔔/🎙/🔄 + "มี N คนรออยู่" + Join Now
  • EP-01: Figma error = toast, ไม่มี empty message · ClickUp error = banner ใน calendar, empty = ข้อความ + ปุ่มสร้าง
  • History: ClickUp การ์ดที่ผ่านไปแล้ว greyed + "Mark all as read" · Figma ไม่ greyed, "Mark as read"

สิ่งที่ POC นี้ตัดสินใจเอง (รอ PM/Design)

  • Badge ขึ้น +1 ทันทีที่ alert มา และเป็น 0 เมื่อเปิด panel (ClickUp) — Figma ไม่ได้วาดช่วงนี้
  • "Join Now" active = เวลาปัจจุบันอยู่ระหว่าง start–end และไม่ถูกยกเลิก
  • เลื่อนเวลาแล้ว alert ตามเวลาใหม่ส่งได้อีก (dedupe key รวม start_at)
  • หลังยกเลิก ปุ่ม Join บนการ์ดเก่าพาไป Calendar แทนห้อง (EP-02) · ปุ่ม Later = ปิด toast
  • Toast ซ้อนกันแนวตั้งมุมขวาบน ใบใหม่อยู่บน · ไม่มี hover/animation ใน Figma — ใช้แบบเรียบ
  • CAL-01 (ผู้ใช้ตัดสิน 2026-10-29 — ขัดกันให้ยึด Figma): สถานะ Connected / ไม่ได้เชื่อม / Expired ตาม Figma ไม่มี badge (ทั้งสองโหมด) · Disconnect ใช้ข้อความ Figma · EP-01 = toast แดง "Connection canceled" ไม่มีปุ่มลองใหม่ (ทั้งสองโหมด) · หน้าเลือกปฏิทิน + Save และการ push meeting เดิม (AC-HP01-5) มีแค่ใน ClickUp ไม่มีแบบใน Figma → POC ทำแบบ General modal ของ Zyra (รอ designer) · EP-02/03 = banner เหลืองใน panel ไม่ใช่บน header · หน้าขออนุญาตของ Google/Microsoft เป็นกล่องจำลอง ไม่ใช่หน้าจริง
  • HP-05 ยกเลิก ตาม Figma 7802:237620: ไอคอน 📅✕ เฉพาะผู้จัด (+ Workspace Admin ตาม ClickUp) · dialog 455px · toast "Event cancelled successfully" · sync ล้มเหลว = toast เหลือง Try again → Open Google Calendar · token หมดอายุ = "Expired token" + Go to setting
  • HP-06 เลื่อน meeting ไม่มีใน Figma — dialog ทำตาม ClickUp (เวลาเดิม, เวลาใหม่, เตือนเวลาชน, ห้องชน = บล็อก, เหตุผล, แจ้ง attendees) · โหมด Figma ใช้ ✏️ Edit แทน
  • กติกาลบ / ยกเลิก (ผู้ใช้กำหนด 2026-10-29): meeting หรือการจองที่สร้างใน Zyra → ลบ/ยกเลิกแล้วยังอยู่ในปฏิทินของทุกคน เป็นพื้นเทา 10% + แถบ #8C99A6 + ขีดฆ่าแดง + "Reason for cancellation" · event จาก Google/Outlook → ลบใน Zyra ไม่ได้ มีไอคอนถังขยะพร้อม tooltip กดแล้วเปิด Google/Outlook ไปลบที่นั่น แล้ว sync กลับมาหายจาก Zyra (ใน POC กด "จำลอง: ลบที่ต้นทางแล้ว sync") · ต่างจาก Figma HP-05 แถว 1 ที่ event หายจากจอผู้ยกเลิก และ ClickUp HP-05 ที่ให้หายจาก calendar ทุกคน
  • ปิดฟอร์มที่กรอกแล้ว (X / Esc / คลิกข้างนอก) → ถามก่อนทิ้ง · ข้อความ toast "Meeting scheduled / updated / cancelled" ตั้งเอง
  • ช่องวันที่ / เวลา ใช้แบบเดียวกับ Announcement (AnnouncementDateField / AnnouncementTimeField ใน announcement-date-time.tsx) — วันที่ DD/MM/YYYY + ปฏิทิน 311px, เวลาทีละ 15 นาที · ของจริงใน CAL-01 ใช้ CalendarMiniMonth แยกอีกตัว ควรเปลี่ยนมาใช้ตัวเดียวกัน
