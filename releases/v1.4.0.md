## ของใหม่

### 1. Environment — แสงตามเวลา + สภาพอากาศ (SC-ENV-01)

ออฟฟิศเปลี่ยนไปตามเวลาจริงและอากาศจริงของสถานที่ที่ workspace ตั้งอยู่

- **แสงตามช่วงเวลา** — เช้า/สาย/เย็น/กลางคืน คิดจากพระอาทิตย์ขึ้น-ตกของพิกัดนั้น ทุกคนเห็นตรงกันเพราะยึดนาฬิกาจาก server ไม่ใช่เครื่องตัวเอง (สมาชิกที่ลอนดอนเปิด workspace กรุงเทพก็เห็นกลางคืนแบบกรุงเทพ)
- **พระอาทิตย์/พระจันทร์** เดินตามส่วนโค้งจริงของวันนั้น พระจันทร์ขึ้นตามเฟสจริงของคืนนั้น
- **effect อากาศบนแผนที่** — clear / partly cloudy / cloudy / fog / drizzle / rain / thunderstorm / snow / windy
- **การ์ดอากาศ 2 ใบ** — "Workspace weather" (ของออฟฟิศ) และ "Your weather" (ของสมาชิกแต่ละคน) ใครตั้งตำแหน่งตัวเองก็เห็นของตัวเองคู่กันไป
- **effect บนแผนที่ยึดของ owner** ถ้า owner ปิดไว้จึงเปลี่ยนไปใช้ของสมาชิกเอง
- **แจ้งเตือนสภาพอากาศรุนแรง** — แบนเนอร์ + แถวในกระดิ่ง ระดับ watch / warning / emergency (emergency ปิดไม่ได้ รอหมดอายุ 10 นาที ที่เหลือกดปิดได้)
- **เสียงบรรยากาศ** ฝน ลม นกร้อง ปรับความดังได้ที่ Setting → Environment และเงียบลงเองระหว่างคุยงาน
- **Setting → Environment** — ตำแหน่ง workspace, แจ้งเตือนอากาศ, แสงตามเวลา, effect อากาศ, เสียง และตำแหน่งของตัวเอง
- **Debug panel (`Cmd + /`)** สำหรับ tester — เปลี่ยนอากาศ/เวลา/เฟสพระจันทร์เฉพาะเครื่องตัวเอง, ยิง alert จริงทั้ง workspace, จำลอง API timeout, ย้ายตำแหน่ง workspace (มีปุ่ม `home` กลับที่เดิม) และบังคับอากาศ/เวลาให้ทุกคนใน VO เห็นพร้อมกัน

ฝั่ง server: ดึงอากาศจาก **TMD → Google → Open-Meteo → cache** ตามลำดับ retry 3 ครั้งแบบ backoff (30 วิ → 2 นาที → 5 นาที) และ cache ราย cell 10 กม. ให้ workspace ในเมืองเดียวกันใช้ร่วมกัน

### 2. Spotlight — ประกาศทั้งชั้น

- เวที + แบนเนอร์ระหว่างถ่ายทอด, แชทของ Spotlight พร้อมนับข้อความที่ยังไม่อ่าน
- ยืนยันก่อนแชร์, ล็อกการแชร์จอของคนอื่นระหว่างถ่ายทอด, ไฮไลต์คนที่กำลังพูด
- ยืนยันก่อนออก + คีย์ลัดหยุดถ่ายทอด

### 3. Room pet

สัตว์เลี้ยงไม่รบกวนคนที่ตั้งสถานะ busy / away / dnd — ไม่หันมอง ไม่เดินเข้าหา ไม่เด้งข้อความ และถ้าคนที่จูงอยู่เปลี่ยนเป็น busy กลางทาง สัตว์เลี้ยงจะกลับโซนตัวเอง

## แก้ไข

- ซูมออกบนหน้าจอโน้ตบุ๊กแล้วเห็นออฟฟิศไม่ครบ / ไม่เข้ากลางจอ
- ขอบดำรอบแผนที่ตอนย่อ-ขยายหน้าต่าง และตอนซูมออกสุด
- พระอาทิตย์ตอนเที่ยงอยู่เลยขอบบนจอ
- เมฆกองอยู่กลางฟ้า ขึ้นไปไม่ถึงยอด
- แถบ alert กับ panel อากาศทับเมนู meeting
- ฝน/พายุ/ลม/หมอก ขึ้นพร้อมกันทั้งแผนที่จนดูไม่เป็นธรรมชาติ — ตอนนี้แต่ละหยด แต่ละใบ มีจังหวะของตัวเอง ส่วนสายฟ้าต่อคิวกัน ฟาดทีละดวงคนละมุมฟ้า
- ปิด "Weather visual effects" แล้วการ์ดอากาศหายไปด้วย (ต้องหายแค่ effect บนแผนที่)
- Setting ทุกแท็บบอก "Settings saved" เมื่อบันทึกสำเร็จ
- รูปในกระดิ่งของการแจ้งเตือนที่ไม่มีคนส่ง เปลี่ยนเป็นโลโก้ Zyra เต็มวง (เดิมขึ้นวงกลม "NE")
- dev API เปิดไม่ขึ้นเพราะ boot migration เขียน CHECK ของ `tb_notification` ทับโดยไม่นับ type ใหม่

## ต้องทำก่อน deploy

### uat

1. **DB migration** `98`–`101` บน uat DB (ไม่ได้รันอัตโนมัติ)
2. **GitHub Environment `uat` ของ zyra-app** — `NEXT_PUBLIC_SPOTLIGHT=true` และ `NEXT_PUBLIC_ENVIRONMENT=true` เพิ่มแล้วทั้งคู่ (2026-09-15) · `NEXT_PUBLIC_ENVIRONMENT` default คือ OFF ถ้าไม่ใส่ฟีเจอร์อากาศจะไม่ขึ้นเลย
3. **Secret `zyra-api-uat-env-json`** — ต้องมี `ENVIRONMENT_ENABLED=true`, `GOOGLE_MAPS_API_KEY`, `TMD_NWP_TOKEN` · `ENVIRONMENT_DEBUG_ALERTS` ปล่อยปิดไว้ (เป็นเครื่องมือ tester บน dev เท่านั้น)

### prod (ตอน tag)

เหมือน uat ทุกข้อ แต่ใช้ GitHub Environment `production` และ secret `zyra-api-prod-env-json` — migration รันผ่าน `zyra-service/prod-db.sh`

`production` ยังไม่มี `NEXT_PUBLIC_ENVIRONMENT` และ `NEXT_PUBLIC_SPOTLIGHT` เลย ต้องเพิ่มก่อน tag ไม่งั้น build ออกมาโดยฟีเจอร์อากาศปิดอยู่ (เคสเดียวกับ pet flag ตอน v1.3.0)

## Patch note สำหรับหน้า Admin → Patch Notes

**Title**: `อัปเดตใหม่ — บรรยากาศในออฟฟิศตามเวลาและอากาศจริง`

**Description**:

> ตอนนี้ออฟฟิศของคุณเปลี่ยนไปตามเวลาและอากาศจริงของสถานที่ที่ workspace ตั้งอยู่แล้ว
>
> **แสงตามเวลา** เช้า สาย เย็น กลางคืน เปลี่ยนตามพระอาทิตย์ขึ้น-ตกจริง ทุกคนในออฟฟิศเห็นตรงกันไม่ว่าจะอยู่ประเทศไหน
>
> **อากาศบนแผนที่** ฝนตก หมอกลง ลมพัด ฟ้าผ่า หิมะ — ตามที่เกิดขึ้นจริงในตอนนั้น พร้อมเสียงบรรยากาศที่ปรับความดังได้ และเงียบลงเองเวลาคุยงาน
>
> **การ์ดสภาพอากาศ** กดที่มุมบนขวาเพื่อดูอุณหภูมิ ความชื้น และลม ทั้งของออฟฟิศและของตำแหน่งตัวคุณเอง
>
> **แจ้งเตือนอากาศรุนแรง** พายุหรือเหตุฉุกเฉินในพื้นที่จะขึ้นแจ้งเตือนให้ทุกคนในออฟฟิศเห็น
>
> ตั้งค่าทั้งหมดได้ที่ Setting → Environment
>
> **Spotlight** ประกาศทั้งชั้นพร้อมเวที แชท และการยืนยันก่อนแชร์จอ
>
> **Room pet** สัตว์เลี้ยงจะไม่รบกวนคนที่ตั้งสถานะไม่ว่าง
