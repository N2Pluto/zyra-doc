## ของใหม่

### 1. Roadmap / Zyra Spotlight — ขึ้นไปแล้วแต่ **ปิดอยู่**

ระบบจัดการ roadmap ของผลิตภัณฑ์: ไทม์ไลน์ฟีเจอร์รายไตรมาส, ฉาก (scene) ของแต่ละฟีเจอร์ที่วางวัตถุได้, และคลัง asset กลาง (รูปนิ่ง / sprite sheet / GIF) ที่ใช้ซ้ำข้ามฟีเจอร์ได้ ฝั่ง landing อ่านผ่าน `/api/public/roadmap` เฉพาะแถวที่ `is_visible` และมีโหมด teaser ที่โชว์เงาปริศนาแทนฉากจริง

**รอบนี้ยังไม่เปิดให้ใช้** — deploy โค้ดขึ้นไปก่อนแบบ dark launch ตามที่ทีมตัดสินใจ กันไว้สองชั้น:

| ชั้น | ตัวแปร | ค่าบน prod | ผล |
|---|---|---|---|
| API | `ROADMAP_ENABLED` | ไม่ได้ตั้ง (default `false`) | route **ไม่ถูกลงทะเบียนเลย** ทุก path ตอบ 404 |
| App | `NEXT_PUBLIC_ROADMAP` | ไม่ได้ตั้ง (default off) | ไม่มีเมนู เข้า `/admin/roadmap` ไม่ได้ |

ยืนยันบน prod จริงแล้วว่า `/api/public/roadmap` และ `/api/admin/roadmap` ตอบ `404` (ดู [ผลตรวจ](#ผลตรวจบน-prod))

**เปิดใช้งานภายหลัง**: ตั้ง `ROADMAP_ENABLED=true` ใน secret ของ api แล้ว restart pod + rebuild app ด้วย build-arg `NEXT_PUBLIC_ROADMAP=true` (เป็น `NEXT_PUBLIC_*` จึง bake ตอน build เปลี่ยน runtime ไม่ได้) — **ไม่ต้องแตะ DB อีก** ตารางสร้างรอไว้แล้ว

### 2. Analytics — ทุก user action มีชื่อ event ของตัวเอง

เดิม 25 ชื่อใน event catalogue ถูกประกาศไว้แต่ไม่มีโค้ดยิงจริง — catalogue อ่านแล้วเหมือนมี coverage ทั้งที่ไม่มี รอบนี้ต่อครบทุกชื่อจากจุดที่ action นั้นผ่านจริง: auth/signup ใน `lib/auth`, การเข้า-ออก workspace และ chat side-action ใน API module, การเข้า virtual office ใน session store, และคลิกบน PixiJS canvas (avatar, room pet, teleport pad) ซึ่ง DOM listener มองไม่เห็นเพราะเป็นพิกเซลที่วาด ไม่ใช่ element

- ตัดสองชื่อที่ซ้ำความหมายทิ้ง — thread reply คือ `Message Sent` ที่มี property `kind`, chat reaction คือ `Reaction Sent` ที่มี property `surface` (รายละเอียดควรอยู่ใน property ไม่ใช่ชื่อ event ที่สอง)
- `Logged Out` บอกสาเหตุแล้ว (user / expired / revoked)
- login ที่ยิงไม่ถึง server นับเป็น failed — metric ที่เงียบไปตอนระบบล่มจะอ่านเหมือนไม่มีอะไรพัง

เปลี่ยนชื่อแบรนด์ใน UI, metadata และ i18n ของ `zyra-app` (35 ไฟล์), ชื่อผู้เขียน patch note ฝั่ง `zyra-api` และ email copy ของ `zyra-notifications`

## แก้ไข

### Virtual Office — zoom (ZYR-1188 / ZYR-1189)

สอง support ticket จากผู้ใช้คนเดียวกัน ต้นเหตุอยู่ห่างกันแค่ handler เดียว

- **zoom วิ่งไปกลางจอ** — ซูมออกหาห้องแล้วจะซูมเข้าไปที่ห้องนั้นไม่ได้ ภาพวิ่งกลับไปตรงกลาง ต้องลากหาใหม่ทุกครั้ง สาเหตุ: handler ไม่เคยอ่านตำแหน่งเมาส์เลย กล้องปัก pivot ไว้กลางจอตายตัว **ตอนนี้ซูมยึดจุดใต้เคอร์เซอร์** จุดที่เล็งอยู่ใต้เมาส์ตลอด
  - ผลข้างเคียงที่ตั้งใจ: **ซูมด้วย scroll จะหยุดให้กล้องตามตัวละคร** จำเป็น เพราะกล้องเป็น exponential follower ที่ดึงกลับหาตัวละครใน ~0.1 วินาที ถ้าไม่หยุดตามจะแก้ ticket ไม่ได้เลย กลับมาหาตัวเองได้ด้วย WASD, click-to-walk, ปุ่ม Locate me บน minimap หรือปุ่ม indicator ที่โผล่ตอนตัวละครหลุดจอ
  - pinch บน trackpad/มือถือ ยึดจุดกึ่งกลางระหว่างสองนิ้วเช่นกัน
- **scroll ไม่ติดเมื่อชี้ "วงใหญ่"** — วงกลมรอบกลุ่มคนตั้งแต่ 2 คนขึ้นไปเป็นปุ่ม HTML ที่ลอยทับแผนที่ handler จึงทิ้ง event ทิ้ง ไม่ซูมและหน้าเว็บก็ไม่เลื่อน เลยรู้สึกเหมือนจุดตาย (ชี้คนเดี่ยว = "วงเล็ก" ไม่เป็นเพราะวาดใน canvas ล้วน) ตอนนี้ overlay ทุกตัวที่วาดบนแผนที่ส่ง gesture ให้กล้อง — facepile, ปุ่ม Ask to Join, ป้ายชื่อโซน, การ์ดโซนล็อก — ส่วนรายการที่เลื่อนได้จริง (member panel, chat) ยังเลื่อนของตัวเองเหมือนเดิม
- อาการกระตุก 1 เฟรมต่อการหมุน scroll 1 ครั้ง ที่เจอระหว่างแก้ — overlay ได้ zoom ใหม่คู่กับตำแหน่งกล้องเก่า

### เสียง

- **ตัดเสียงจักจั่นออก** — บ่ายที่อุณหภูมิ ≥ 30 °C เคยเล่นเสียงจักจั่น ซึ่งในไทยคือเกือบทุกบ่าย กลายเป็นเสียงที่คนได้ยินเกือบตลอดวันทำงานและมีคนบอกว่ารำคาญ ตอนนี้บ่ายใช้เสียงนกเหมือนบ่ายที่ไม่ร้อน — ไม่ได้ตัดเป็นเงียบสนิทเพราะจะเท่ากับเอา ambience ช่วงบ่ายออกทั้งหมด เสียงอื่นไม่แตะ (นก, เย็น, กลางคืน, จิ้งหรีด, ไก่ขัน, ฝน, พายุ, หิมะ, ลม) ไฟล์เสียงกับ threshold ยังอยู่ รอ clip ใหม่มาแทน

### Analytics

- แท็บ Audio และแถวแจ้งเตือนที่ผูกกับเสียง (~ครึ่งหนึ่งของ toggle ใน Settings) ไม่ยิง event เลย เพราะ modal บันทึกผ่าน debounce ของตัวเองไม่ผ่าน store

## DB Migration

`zyra-api/migrations/103_roadmap.sql` — **รันบน prod AlloyDB แล้วก่อน push tag** (2026-09-18 ผ่าน IAP tunnel)

สร้าง 3 ตาราง + 5 index:

| ตาราง | ใช้ทำอะไร |
|---|---|
| `tb_roadmap_asset` | คลัง asset กลาง (image / sprite / gif) พร้อมกรอบเฟรมที่ detect จาก alpha ตอนอัปโหลด |
| `tb_roadmap_feature` | 1 ฟีเจอร์ = 1 จุดบนไทม์ไลน์ (quarter คำนวณจาก release_date ช่วงละ 4 เดือน) |
| `tb_roadmap_scene_object` | วัตถุที่วางในฉากของแต่ละฟีเจอร์ |

- **additive ล้วน** — `CREATE TABLE / INDEX IF NOT EXISTS` ไม่มี `ALTER` ตารางเดิมสักบรรทัด แตะของเดิมแค่ FK `created_by/updated_by → tb_user(id) ON DELETE SET NULL`
- idempotent รันซ้ำไม่พัง
- มี `103_roadmap.down.sql` คู่กัน (DROP ทั้ง 3 ตารางเรียงตาม FK)
- ตารางว่างและไม่มีโค้ดไหนอ่านจนกว่าจะเปิด flag
