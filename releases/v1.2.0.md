## 🎉 อัปเดตใหม่ Zyra v1.2.0

### สำหรับผู้ใช้ทั่วไป

**ตั้งค่าเสียงแจ้งเตือนได้เอง**
เข้า Setting → Audio ปิด/เปิดเสียงแยกได้ทีละแบบ — ข้อความแชท, มีคนแท็กเรา, เข้าวงคุย, เข้าห้องประชุม, เคาะประตู, โบกมือ, ขอเปิดไมค์/กล้อง, ยกมือ, แชร์หน้าจอ

**ตั้งค่าติดตามไปทุกเครื่อง**
ตั้งค่าใน Setting → General แล้วเปลี่ยนเครื่อง/เปลี่ยนเบราว์เซอร์ ค่าเดิมยังอยู่ (เมื่อก่อนต้องตั้งใหม่ทุกเครื่อง)

**เลือกได้ว่าจะให้ระบบทำอะไรอัตโนมัติบ้าง**
เดิมระบบทำให้เสมอ ตอนนี้ปิดได้ถ้าไม่ชอบ
- กล้องเด้งกลับมาที่ตัวเราทุกครั้งที่คลิกเดิน
- เดินกลับโซนตัวเองเมื่ออยู่ในห้องประชุมเฉย ๆ นาน 45 นาที
- เปลี่ยนสถานะเป็น Away เมื่อไม่ขยับ 30 นาที
- ออกจากออฟฟิศเมื่อ Away ครบ 2 ชั่วโมง

**เดินคล่องขึ้น**
- ดับเบิลคลิกบนโต๊ะ ตู้ หรือของอื่น ๆ เดินไปได้แล้ว (ตัวละครจะไปยืนตรงช่องว่างที่ใกล้ที่สุด) — เมื่อก่อนคลิกแล้วไม่ขยับ
- คลิกพลาดทีเดียวไม่ทำให้ตัวละครหยุดค้างหรือถูกดีดย้อนกลับอีกแล้ว

**ห้องประชุมดูง่ายขึ้น**
- แถวรูปหน้าคนไม่ล้นออกไปทับห้องข้าง ๆ ตอนซูมออกแล้ว
- กดรูปหน้าคนในแถว = เปิดเมนูของคนนั้นได้เลย (เหมือนคลิกตัวเขาในแผนที่)
- กดปุ่ม "+3", "+8" เพื่อดูรายชื่อคนในห้องทั้งหมด และกดดูเพิ่ม/ย่อได้ (เมื่อก่อนขึ้นตัวเลขไว้เฉย ๆ กดไม่ได้)

**ซูมออกแล้วยังอ่านรู้เรื่อง**
- ซูมออกมาก = เห็นเป็นวงกลมรูปโปรไฟล์ / ซูมเข้ามาหน่อย = เห็นตัวละครกับชื่อ
- ชื่อห้องจางลงเล็กน้อยเพื่อไม่ตีกับชื่อคน (ชี้เมาส์ก็ชัดเต็ม)
- สัญลักษณ์ "คนกำลังพูด" ไม่หายตอนซูมออกอีกแล้ว

**หาคนหาห้องง่ายขึ้น**
กดชื่อคนหรือห้องในแผงรายชื่อ เป้าหมายจะขึ้นไฮไลต์ **สีม่วง** บนแผนที่ ทำให้เห็นชัดว่าอันไหนที่เรากด

**ลิงก์เชิญใช้งานได้แล้วถ้าเราเป็นสมาชิกอยู่**
เมื่อก่อนถ้าลิงก์ถูกใช้ครบโควตาหรือที่นั่งเต็ม คนที่เป็นสมาชิกอยู่แล้วกดลิงก์จะเจอหน้า "เข้าไม่ได้" ตอนนี้เข้าได้ปกติ

**ภาพซ้อนทับถูกต้องขึ้น**
ตัวละครไม่ทะลุของ ไม่ถูกของแขวนผนังบังแปลก ๆ และของตกแต่งไม่จมพื้นหรือหายไปหลังโต๊ะ

### สำหรับ Owner / Admin (เพิ่มจากด้านบน)

**เปลี่ยนชื่อห้องได้จากในออฟฟิศเลย — ไม่ต้องเข้าโหมดแก้แผนที่**
ชี้เมาส์ที่ป้ายชื่อห้องหรือห้องประชุม → มีไอคอนดินสอโผล่มา → กดแก้ชื่อได้ทันที ทุกคนที่อยู่ในออฟฟิศเห็นชื่อใหม่พร้อมกัน (ชื่อยาวได้ 20 ตัวอักษร)
สมาชิกทั่วไปจะไม่เห็นไอคอนนี้

**โควตาลิงก์เชิญนับถูกต้องแล้ว — เรื่องนี้สำคัญ**
เมื่อก่อนระบบนับทุกครั้งที่มีคน "กดลิงก์" ทำให้ลิงก์ที่ตั้งไว้ 100 ครั้ง ใช้หมดตอนมีคนกดเข้า-ออกแค่ประมาณ 50 คน แล้วคนที่เหลือเข้าไม่ได้เลย
ตอนนี้นับเฉพาะคนที่เข้ามาเป็นสมาชิกใหม่จริง ๆ — เรากดลิงก์ตัวเองเพื่อเช็กได้ไม่เปลืองโควตา และเมื่อโควตาเต็ม สมาชิกเดิมยังใช้ลิงก์เข้าได้ปกติ

**ปุ่ม "ติดผนัง" (On wall) ชัดเจนขึ้น**
- ใช้ได้เฉพาะกับของที่วางอยู่บนกำแพงจริง ๆ ถ้าไม่ใช่ ปุ่มจะเป็นสีเทาและมีข้อความบอกเหตุผล (เมื่อก่อนกดได้แต่ไม่เกิดอะไรขึ้น)
- ของที่แขวนบนกำแพงชัด ๆ ตอนนี้กดได้แล้ว (เมื่อก่อนบางชิ้นกดไม่ได้)
- ย้ายของแล้วสถานะยังถูกต้อง ไม่ต้องปิด-เปิดใหม่ และถ้าย้ายออกจากกำแพงระบบจะปลดให้เอง
- ของที่วางไว้เดิมทั้งหมดยังอยู่ครบ ไม่ต้องแก้อะไร

2. **zyra-api** (frontend เรียก route ใหม่)
3. **zyra-ws** (event `zone_renamed` บน Redis channel `vo:zone`)
4. **zyra-app**

### หมายเหตุพฤติกรรม
- ค่า General/Audio ที่ผู้ใช้เคยตั้งไว้ใน localStorage (`zyra_outside_display`, `zyra_idle_*`) ถูก migrate ขึ้น DB ครั้งเดียวตอน hydrate และลบ key ทิ้งหลัง PATCH สำเร็จเท่านั้น
- ค่าเริ่มต้นของทุก toggle ใหม่คือ **ON** — ผู้ใช้ที่ไม่เคยแตะ setting จะได้พฤติกรรมเดิมทั้งหมด
- โซน Spotlight ยังไม่มีปุ่ม rename (ตามที่ตกลงกับผู้ใช้ — meeting/room เท่านั้น)
- Trade-off ที่ยอมรับแล้ว: ของ on-wall ไม่ได้อยู่หน้าสุดทั้งแผนที่อีก ของที่อยู่แถวลึกกว่าจริงบังได้ เพื่อให้ตัวละครอยู่ z-index ปกติ
