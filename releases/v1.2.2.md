## 🎉 อัปเดตใหม่ Zyra v1.2.2

### สำหรับผู้ใช้ทั่วไป

**เข้าสู่ระบบด้วย Google แล้วรูป/ชื่อ/สิทธิ์ไม่หายอีกต่อไป**
เมื่อก่อนทุกครั้งที่ล็อกอินด้วย Google ระบบจะเขียนทับรูปโปรไฟล์ที่อัปโหลดเอง ชื่อที่ตั้งเอง และลดสิทธิ์ admin กลับเป็น member โดยไม่ตั้งใจ — เกิดง่ายที่สุดตอน session หมดอายุแล้วล็อกอินใหม่ ตอนนี้ Google จะอัปเดตเฉพาะข้อมูลที่ยังไม่เคยตั้งเองเท่านั้น

**ตัดรูปโปรไฟล์ได้ลื่นขึ้น ไม่มีขอบดำ**
ตัดรูป PNG ที่มีพื้นหลังโปร่งใสแล้วไม่ขึ้นเป็นสีดำอีกแล้ว และรูปถ่ายจากมือถือที่ไฟล์ใหญ่มาก (เช่นถ่ายจาก iPhone) จะไม่ค้างหรืออัปโหลดไม่สำเร็จอีกต่อไป

**คลิกตัวละครในโซนแล้วเปิดเมนูตัวละครได้ถูกต้อง**
เมื่อก่อนคลิกคนที่ยืนอยู่ในโซน (เช่นห้องประชุม) จะเปิดเมนูของโซนแทนเมนูของคนนั้น ทำให้กด Wave ไม่ได้ ตอนนี้คลิกแล้วเปิดเมนูตัวละครถูกต้อง รวมถึงแก้จุดคลิกของคนที่นั่งอยู่ให้ตรงกับตำแหน่งที่วาดจริง

**เดินออกจากห้องประชุมแล้วเมนูไม่ค้างอีกแล้ว**
คลิกพื้นเพื่อเดินออกจากห้องประชุมที่ว่างเปล่า เมื่อก่อนแผงห้องประชุมจะค้างอยู่บนหน้าจอทั้งที่ออกมาแล้ว ตอนนี้ปิดให้ถูกต้อง

**เปลี่ยนรูปโปรไฟล์แล้วป้ายชื่อโซนที่จับจองไว้อัปเดตทันที**
เมื่อก่อนป้ายชื่อ/รูปบนโซนส่วนตัวที่จับจองไว้ยังเป็นรูปเก่าจนกว่าจะรีเฟรชหน้า ตอนนี้อัปเดตทันทีทั้งฝั่งเราเองและฝั่งคนอื่นที่เห็น

**เลือกอุปกรณ์ไมค์/กล้องแล้ว ระบบจำไว้ให้จริง**
กด "ไม่เปลี่ยน" ตอนระบบแจ้งเตือนว่ามีอุปกรณ์ใหม่เสียบเข้ามา เมื่อก่อนแค่ปิด popup เฉย ๆ ไม่ได้บันทึกอะไร รอบถัดไปที่เข้าประชุม/เชื่อมต่อใหม่ระบบจะสลับไปอุปกรณ์นั้นให้อีก ตอนนี้กดปฏิเสธแล้วจำไว้จริง ไม่ถามซ้ำ

### สำหรับ Owner / Admin (เพิ่มจากด้านบน)

**แก้ช่องโหว่ความปลอดภัยหลายจุด**
ปิดช่องทางที่คนนอกอาจใช้ลิงก์เชิญของ workspace อื่นเข้ามายึด workspace, แก้จุดที่ตรวจสิทธิ์ข้าม workspace ไม่ครบในบางหน้าจัดการแผนที่/วัตถุ, และป้องกันไฟล์ภาพขนาดใหญ่ผิดปกติที่อาจทำให้ระบบค้าง (รายละเอียดเชิงเทคนิคด้านล่าง)

**Pet Management (admin) — ปรับปรุงต่อเนื่อง**
หน้าอัปโหลดสัตว์เลี้ยงมี tooltip อธิบาย spritesheet และรองรับหลายภาษาแล้ว ปรับ layout หน้ารายละเอียด/อัปโหลดให้ responsive ขึ้น — ฟีเจอร์นี้ยังอยู่ระหว่างพัฒนา ยังไม่เปิดให้ผู้ใช้ทั่วไปใช้งาน

### Security-audit findings ที่แก้ (zyra-api, commit `c195ba1`)
- **C1** — join-link endpoints ไม่บังคับสิทธิ์ owner/admin (unauthenticated → workspace takeover ผ่าน admin invite link)
- **H1** — ไม่ตรวจว่า placement เป็นของ map นั้นจริงก่อนแก้ไขฝั่ง owner (cross-workspace IDOR)
- **H2** — แก้ไข/ลบ map ไม่ตรวจว่า map เป็นของ workspace ที่เรียก (IDOR)
- **H3** — ออก LiveKit media token ไม่เช็ค membership + zone อยู่ใน workspace ก่อน
- **H4** — เพิ่ม internal endpoint สำหรับ zyra-ws ตรวจสอบ conversation-membership (chat authz)
- **H7** — ปฏิเสธรูปที่มี dimension ใหญ่ผิดปกติก่อน decode (ป้องกัน decompression-bomb DoS)

### Endpoint ใหม่
- `pet_xp_config_handler` / `pet_handler` — endpoint ดึง pet activity definitions และ metadata (ใช้โดย admin pet-management xp-configuration)
- internal conversation-membership endpoint (H4 ด้านบน) — ใช้โดย zyra-ws เท่านั้น ไม่ expose ให้ frontend ทั่วไป

### Migration
- **87 — `tb_pet_xp_activity_definition`** — สร้างตารางใหม่ + seed ค่าเริ่มต้น 10 กิจกรรม (idempotent, `ON CONFLICT DO NOTHING`)
  (`migrations/87_pet_xp_activity_definitions.sql`, มีไฟล์ `.down.sql` คู่กัน)

### หมายเหตุพฤติกรรม
- Pet Management ยังเป็นโมดูล admin-only ที่กำลังพัฒนาต่อเนื่อง (ดู `zyra-doc/plan/PetManagement/`) — commit ใน release นี้เป็นงานสะสมระหว่างทาง ไม่ใช่การเปิดตัวฟีเจอร์เต็มรูปแบบ
- Google-login fix เปลี่ยนเฉพาะ logic การ merge claim (`mergeGoogleClaims`) เป็น pure function แยกออกมา ไม่มี data migration ที่ต้องรันย้อนหลัง — ผู้ใช้ที่เคยโดนเขียนทับรูป/ชื่อ/สิทธิ์ไปแล้วก่อนหน้านี้ ต้องตั้งค่าคืนเอง (ไม่มี auto-restore)
- avatar crop fix ลดขนาด buffer สูงสุดที่ประมวลผลเหลือ 1024px ฝั่ง longest edge (API re-encode เป็น 400×400 อยู่แล้ว) — ไม่กระทบคุณภาพรูปที่ผู้ใช้เห็น
