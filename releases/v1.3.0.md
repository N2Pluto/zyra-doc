## 🐾 อัปเดตใหม่ Zyra v1.3.0 — Room Pet

รอบนี้เป็นฟีเจอร์ใหญ่ตัวเดียว: **สัตว์เลี้ยงประจำห้อง** เจ้าของ workspace วางสัตว์เลี้ยงลงในห้องได้ แล้วทุกคนที่นั่งอยู่ในห้องนั้นช่วยกันเลี้ยงให้มันโต

### สำหรับผู้ใช้ทั่วไป

**สัตว์เลี้ยงเดินไปมาในห้องของตัวเอง**
มันเดินสำรวจห้องเอง หยุดพักเป็นระยะ ไม่เดินออกนอกห้อง ไม่เหยียบทับตัวละคร และไม่เข้าไปในห้องประชุม พอมีคนเดินเข้ามาใกล้มันจะหยุดแล้วหันมาทักทันที

**ลูบหัวได้**
เดินเข้าไปใกล้แล้วกดปุ่มรูปมือบนป้ายชื่อ หรือกดปุ่ม `P` — ได้คนละ 1 ครั้งทุก 30 นาที และเฉพาะคนที่มีโต๊ะ (private zone) อยู่ในห้องนั้น

**สะสม XP แล้วโตขึ้นทีละขั้น**
กิจกรรมประจำวันของคุณ (ล็อกอิน อยู่ในออฟฟิศ ส่งข้อความ เข้าประชุม ฯลฯ) กลายเป็น XP ของสัตว์เลี้ยงในห้อง พอครบเกณฑ์มันจะวิวัฒนาการ ไข่ → เด็ก → โต → ร่างสมบูรณ์ พร้อมแอนิเมชันให้ทุกคนในห้องได้ดู

**เควสประจำห้อง**
รายการเควสเป็นของห้อง ไม่ใช่ของใครคนเดียว — ทุกคนในห้องช่วยกันทำ นับรวมกัน

**พาไปเดินเล่นได้**
กดปุ่มรอยเท้าแล้วสัตว์เลี้ยงจะเดินตามคุณไปทั้งออฟฟิศ กดปล่อยแล้วมันเดินกลับห้องตัวเอง (ตอนเป็นไข่ยังพาไปไม่ได้)

**มีเสียงตามชนิด**
แมว หมา ไก่ มีเสียงของตัวเองตอนถูกลูบ และมีเสียงพิเศษตอนวิวัฒนาการ ปิดได้ที่ **Setting → Notifications → PET → Pet sounds**

**แชร์เข้าห้องแชท**
ส่งการ์ดสัตว์เลี้ยงที่โตแล้วอวดเพื่อนในห้องแชทได้

**แจ้งเตือน**
เมื่อสัตว์เลี้ยงโตขึ้น ถึง milestone หรือถูกปล่อยให้เหงานานเกินไป

### ปรับปรุงอื่น ๆ ใน Virtual Office

- **คลิกเดินแล้วมีหมุดบอกปลายทาง** เห็นชัดว่ากำลังจะไปไหน วางถูกชั้นเหนือเก้าอี้และเฟอร์นิเจอร์
- **เข้าออฟฟิศเร็วขึ้น** โหลดภาพฉากล่วงหน้าตั้งแต่หน้า loading

### สำหรับ Admin

- **Pet Management** — สร้าง pet type, อัปโหลด spritesheet แยกตาม stage และท่าทาง, ตั้ง frame rate ต่อ stage, เลือกหมวด (แมว / หมา / ไก่), ตั้งค่า XP ของแต่ละกิจกรรม
- **Map Editor** — วางสัตว์เลี้ยงลงในห้อง, badge บอกว่าห้องไหนมีสัตว์เลี้ยงแล้ว, สั่งเปลี่ยน stage จากเมนูของหมุดได้
