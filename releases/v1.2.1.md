## 🎉 อัปเดตใหม่ Zyra v1.2.1

### สำหรับผู้ใช้ทั่วไป

**รู้ทันทีเมื่อ Zyra มีของใหม่ — ไม่ต้องไปหาเอง**
เข้าระบบแล้วมีอัปเดตใหม่ จะมี popup สรุปสิ่งที่เปลี่ยนขึ้นให้อ่านทันที ถ้ากำลังอยู่ในห้องประชุมจะไม่รบกวน — ขึ้นเป็นการ์ดเล็กที่มุมจอแทน กดดูรายละเอียดหรือปิดไว้ดูทีหลังก็ได้ (ดูย้อนหลังได้ที่ Help Center → Patch Notes)

**หน้า Setting จัดใหม่ ครบขึ้น**
แยกเป็น 3 แท็บ General / Audio / Notifications ชัดเจน — เพิ่มสวิตช์เปิด/ปิดแจ้งเตือนอีกหลายรายการที่เมื่อก่อนไม่มีให้ปิด (เช่น มีคนตอบกลับ, เชิญเข้าร่วมวงคุย, คำเชิญ/แจ้งเตือนกิจกรรม)

**ตั้งค่าไมค์/กล้อง/เสียงติดตามไปทุกเครื่องจริง ๆ**
อุปกรณ์ที่เลือกไว้, ระดับเสียง, เอฟเฟกต์พื้นหลังกล้อง ฯลฯ ตอนนี้ผูกกับบัญชีแล้ว ไม่ใช่แค่เครื่อง/เบราว์เซอร์ที่ตั้งไว้เท่านั้น

**เสียงแจ้งเตือนใหม่**
เพิ่มเสียงแจ้งเตือนตอนมีคนแท็ก (mention) แยกจากเดิม และแยกเสียง "ขอเปิดไมค์" กับ "ขอเปิดกล้อง" ออกจากกันแล้ว

**ไมค์หลุดเสียงเองตอนถอดปลั๊กหูฟัง Bluetooth — แก้แล้ว**
เมื่อก่อนปิดหูฟัง Bluetooth ระหว่างประชุมแล้วไมค์เงียบไปเลย ต้องออกแล้วเข้าห้องใหม่ ตอนนี้ระบบดึงไมค์เครื่องกลับมาให้เองอัตโนมัติ

**เห็นตัวเองตอนเดินหลุดจอ**
เดินไปไกลจนตัวละครหลุดขอบจอ จะมีลูกศรชี้ทิศทางที่ขอบจอ กดเพื่อเลื่อนกล้องกลับมาหาตัวเองได้ทันที

**กล้องโฟกัสตัวละครตรงกลางจริง ๆ**
เมื่อก่อนตัวละครค้างอยู่ค่อนไปทางล่างจอเล็กน้อย ตอนนี้อยู่กลางจอพอดีตอนเดิน

**ออกจากห้องประชุมแล้วเมนู/รายชื่อไม่ค้าง**
คนที่เดินออกจากห้องประชุมไปแล้ว จะหายจากแผงรายชื่อ "กำลังประชุม" ทันที ไม่ค้างอยู่อีก 3-8 วินาทีเหมือนเมื่อก่อน

**คลิกเดินแม่นขึ้น ไม่มีสะดุด**
ยกเลิกการเดินกลางทางแล้วตัวละครไม่ค้างนอกโซนอีกต่อไป และกด "ไปหา" คนที่กำลังนั่งอยู่จะแจ้งเตือนแทนที่จะไม่ตอบสนองเฉย ๆ

**Pop-out หน้าจอ (outside display) พอดีจอทุกระดับซูม**
เมื่อก่อนถ้าเบราว์เซอร์ซูมไม่ใช่ 100% หน้าต่าง pop-out จะเบี้ยวหรือมีของล้นขอบ ตอนนี้ปรับขนาดให้พอดีเสมอไม่ว่าจะซูมเท่าไหร่

### สำหรับ Owner / Admin (เพิ่มจากด้านบน)

**เขียนประกาศอัปเดต (Patch Notes) เองได้**
มีหน้าจัดการใหม่สำหรับเขียน/แก้ไข/เผยแพร่ patch note ให้สมาชิกทั้งทีมเห็น — เผยแพร่ก่อนหรือพร้อมตอนที่ deploy เวอร์ชันใหม่

**ปิดช่องโหว่ที่ cookie ปลอมสามารถหลอกเปิดหน้า admin ได้**
เมื่อก่อนระบบเช็คแค่ว่ามี cookie session อยู่หรือเปล่า ไม่ได้ตรวจว่า valid จริง ทำให้ปลอม cookie เข้าหน้า admin แบบ SSR (เห็นโครงหน้าก่อน login) ได้ ตอนนี้ตรวจสอบ session จริงกับ server ทุกครั้งก่อนปล่อยเข้า

### หมายเหตุพฤติกรรม
- **Pet Management ยังไม่เปิดให้ผู้ใช้ทั่วไป** — โมดูลนี้อยู่เบื้องหลัง feature flag (`NEXT_PUBLIC_PET`, bake ตอน build ต่อ environment) และเมนู notification ของ pet ถูกซ่อนไว้จนกว่าฟีเจอร์จะพร้อมเปิดจริง (ดู [[pet-egg-evolution-shared-gif]])
- Patch notes เผยแพร่ผ่าน client build-detection เท่านั้น (ไม่ push, ไม่ WS) — ต้อง publish note **ก่อนหรือพร้อม** deploy เวอร์ชันใหม่ ไม่มีการ schedule ล่วงหน้า (ดู [[sc-anc-07-patch-notes]])
- `media_settings` sync ผ่าน debounced PATCH โดย localStorage ยังเป็น live cache ต่อ tab, DB เป็น cross-device source of truth — GET ที่ fail จะไม่เขียนทับ prefs ในเครื่อง (ดู [[settings-persistence-model]])
- Notifications tab เขียนลง 2 blob คนละที่ (`audio_settings` เดิม + `notification_settings` ใหม่) ตาม field — ดู [[setting-notifications-tab]] ก่อนแก้ต่อ
- proxy session-validation fail-open เมื่อ backend ล่ม/timeout — กัน backend สะดุดแล้วล็อกทุกคนออกทั้งเว็บ (ดู [[proxy-session-validation-gate]])
