## 🐾 อัปเดต Zyra v1.3.1

รอบนี้เป็น **patch ต่อจาก v1.3.0** — ปรับ Room Pet ให้ลูบแล้วได้ผลจริง แก้เสียงคุยกันที่พังในบางห้อง และทำโหมดตกแต่งห้องส่วนตัวให้ลื่นขึ้น

### สำหรับผู้ใช้ทั่วไป

**ลูบหัวสัตว์เลี้ยงแล้วได้ XP ทุกคน**
เดิมทั้งห้องได้ XP จากการลูบรวมกันแค่วันละ 1 ครั้ง — ใครลูบก่อนได้คนเดียว ตอนนี้**ทุกคนที่ลูบได้ +1 XP ให้สัตว์เลี้ยงเสมอ** ห้องที่มีสมาชิกหลายคนช่วยกันลูบก็โตเร็วขึ้นตามจำนวนคนจริง ๆ

**ลูบได้คนละครั้งทุก 1 ชั่วโมง** (เดิม 30 นาที)
ปุ่มรูปมือจะซ่อนไว้จนกว่าจะครบชั่วโมง แล้วโผล่มาใหม่เอง

**รายการเควสไม่มีแถว "เล่นกับสัตว์เลี้ยง" แล้ว**
เพราะการลูบไม่มีเพดานต่อวันอีกต่อไป จึงไม่มีตัวเลข "กี่ครั้งจากกี่ครั้ง" ให้เดินหน้า — ลูบได้เรื่อย ๆ ชั่วโมงละครั้ง

**เสียงคุยกันกลับมาใช้ได้ในห้องแชทและโหมด Spotlight**
ก่อนหน้านี้บางห้อง (chat space / spotlight) ขอสิทธิ์เสียงแล้วเซิร์ฟเวอร์ตอบ error ทำให้เข้าเสียงไม่ได้เลย — แก้แล้ว

**เสียงสัตว์เลี้ยงไม่ค้างในแถบสื่อของเบราว์เซอร์**
ผู้ใช้ Zen / Firefox จะไม่เห็นรายการเสียงกองสะสมในแผงควบคุมสื่ออีก

**โหมดตกแต่งห้องส่วนตัวลื่นขึ้น**
ย้าย/วางของได้ทันทีในเครื่อง แล้วกด Done ครั้งเดียวเพื่อบันทึกทั้งชุด (เดิมยิงบันทึกทีละชิ้น)

**ชื่อและรายละเอียด workspace ถูกบันทึกจริงตอนกด publish**

**เดินชนของที่หายไปแล้วไม่ได้อีก**
เวลามีคนปล่อยคืนโต๊ะ (unclaim) หรือกู้ห้องกลับมา ตารางสิ่งกีดขวางจะถูกอัปเดตทันที ไม่มีกำแพงล่องหนค้างอยู่

**เควสของสัตว์เลี้ยงเปิดให้คนที่เพิ่งจองโต๊ะทีหลัง**
เดิมถ้าเข้าออฟฟิศก่อนจองโต๊ะ เควสของวันนั้นจะไม่นับให้เลย

## สำหรับทีมพัฒนา

### Migration

**ไม่มี migration ที่ต้องรันบน prod** — รอบนี้มีเพียง `97_pet_xp_play_enabled.sql` ซึ่งตรวจแล้วเป็น **no-op บน prod และ uat** เพราะ `xp_play_with_pet` เปิดอยู่แล้วใน config v3 ของทั้งสอง env (ค่า `{"times":1,"xp":1,"enabled":true}` ตรงกับเป้าหมายของ migration) — เฉพาะ dev เท่านั้นที่เคยถูกปิดไว้ (v12/v13) และถูก patch เป็น v14 แล้ว

รันซ้ำได้ปลอดภัย (idempotent) และมี `.down.sql`

### Build-time env

ไม่มีตัวใหม่ — `NEXT_PUBLIC_ROOM_PET` / `NEXT_PUBLIC_PET` ตั้งไว้แล้วบน GitHub Environment `production` ตั้งแต่ v1.3.0

### กติกาใหม่ของการลูบ (เชิงเทคนิค)

| | v1.3.0 | v1.3.1 |
|---|---|---|
| โควตา XP | `xp_play_with_pet` โควตา**ของห้อง** `times: 1`/วัน | **ไม่มีโควตารายวัน** (`SkipDailyQuota`) — จ่ายทุกคน |
| Cooldown | 30 นาที/คน/pet | **1 ชั่วโมง**/คน/pet (`PetStrokeCooldown`) — เป็นข้อจำกัดเดียวที่เหลือ |
| Daily quest | มีแถว `xp_play_with_pet` | ตัดออกทั้ง API (`Status`) และ client (`buildPetDailyQuests`) |
| `RoomPetActivityQuota.Limit` | `times` จาก config | `0` = ไม่มีเพดาน |

`times` ยังคาไว้ที่ 1 ใน config เพราะ validator ไม่รับ `times <= 0` สำหรับ activity ที่เปิดอยู่ — โค้ดไม่อ่านค่านี้สำหรับ stroke แล้ว หน้า admin จึงแสดงแถวนี้เป็น "ไม่จำกัด · 1 ครั้ง/ชั่วโมง/คน" แทน input

**วัดยังไง:**
```sql
SELECT count(*) FROM tb_room_pet_stroke WHERE stroked_at > now() - interval '7 days';
SELECT count(*) FROM tb_room_pet_xp_event
 WHERE activity = 'xp_play_with_pet' AND created_at > now() - interval '7 days';
```
