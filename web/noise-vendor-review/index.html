1

Krisp

แนะนำ

เทคโนโลยีตัวเดียวกับที่อยู่ในโปรแกรมประชุมดัง ๆ ที่คนใช้กันทั่วโลก มีโมเดลชื่อ BVC ที่ตัดเสียงคนอื่นออกโดยเฉพาะ ประมวลผลบนเครื่อง user ทั้งหมด เสียงไม่ออกไปไหน

ต้องคุย sales ราคา $8–16/เดือน ที่เห็นในเว็บคือแอปสำหรับผู้ใช้ทั่วไป ไม่ใช่ราคาที่เราจะจ่าย
  • +ตัดเสียงคนอื่นพูดได้จริง — เป็นสินค้าที่ขายอยู่แล้ว ไม่ใช่งานวิจัย
  • +ใช้กับระบบเดิมได้เลย ไม่ต้องรื้อ ไม่ต้องย้ายไปใช้บริการเจ้าอื่น
  • +เสียงไม่ถูกส่งขึ้น cloud — ตอบลูกค้าองค์กรเรื่องความปลอดภัยได้สบาย
  • −ยังไม่รู้ราคา ต้องยื่นขอแล้วรอ sales ตอบ จึงควรเริ่มติดต่อทันที
  • −user ต้องใส่หูฟัง ถึงจะได้ผลเต็มที่ — ถ้าใช้ไมค์โน้ตบุ๊กจะยังได้ยินเสียงคนข้าง ๆ อยู่
2

ai-coustics

ตัวเทียบราคา

เจ้าใหม่จากเยอรมนี ทำได้เหมือน Krisp คือแยกเสียงคนพูดหลักออกจากเสียงคนอื่น จุดเด่นคือบอกราคาชัดเจนบนเว็บ และให้ทดลองฟรีทันทีโดยไม่ต้องคุยกับใคร

$135–540 ต่อเดือน (จ่ายรายปี) ตามจำนวนนาทีที่ใช้ · ทดลองฟรี 30 วัน
  • +ตัดเสียงคนอื่นพูดได้เหมือนกัน และใช้กับระบบเดิมได้
  • +รู้ราคาทันที ทำให้วางงบได้ และใช้เป็นไพ่ต่อรองกับ Krisp
  • +ทดลองได้เองเลย ไม่ต้องรอ sales
  • −เป็นเจ้าใหม่กว่า มีคนใช้งานจริงน้อยกว่า Krisp มาก
  • −หน่วงกว่า Krisp เล็กน้อย และต้องทดสอบยืนยันว่าใช้ในเบราว์เซอร์ได้จริง
3

LiveKit Cloud

ไม่แนะนำ

แทนที่จะซื้อตัวตัดเสียงมาติดเอง ก็ย้ายไปใช้บริการสำเร็จรูปของ LiveKit ที่มีของ Krisp กับ ai-coustics ให้พร้อมใช้ ฟังดูง่ายที่สุด แต่แพงที่สุดและต้องรื้อของเดิม

$50–500 + ค่าต่อนาที ต่อเดือน · ตัวที่แก้ปัญหาเราคิดเพิ่มต่างหากอีก $0.0012 ต่อนาที
  • +ไม่ต้องพัฒนาเอง เปิดใช้ได้เร็ว
  • −ต้องทิ้งเซิร์ฟเวอร์เสียงที่เราลงทุนทำเองไปแล้ว แล้วย้ายไปใช้ของเขา
  • −แพงกว่าเกือบเท่าตัว เมื่อผู้ใช้เยอะขึ้น เพราะจ่ายทั้งค่าระบบและค่าตัดเสียง
  • −สุดท้ายก็คือของ Krisp ตัวเดิม — จ่ายผ่านคนกลางแทนที่จะซื้อตรง

ไม่แก้เรื่องเสียงคนพูด แต่ทำให้เสียงสะอาดขึ้น — ฟรี

4

DeepFilterNet3

ทำคู่ขนานได้เลย

โอเพนซอร์สที่เอามาใช้เชิงพาณิชย์ได้ ไม่มีค่าลิขสิทธิ์ ตัดเสียงพัดลม แอร์ คีย์บอร์ด ได้ดีกว่าตัวที่เราใช้อยู่ตอนนี้ชัดเจน ทีมเราเสียบเข้าโค้ดเดิมเองได้ ไม่ต้องคุยกับใคร

ฟรี ไม่มีค่าต่อนาที ไม่มีสัญญา · ใช้เวลาพัฒนาราว 2–3 วัน
  • +ไม่ต้องรออนุมัติงบ เริ่มได้ทันที และเห็นผลก่อนใคร
  • +ไม่มีค่าใช้จ่ายเพิ่มเลยแม้ผู้ใช้จะโตขึ้นเท่าตัว
  • +เสียงไม่ออกนอกเครื่อง user เหมือนกัน
  • −ไม่ตัดเสียงคนอื่นพูด — ปัญหาหลักที่ user บ่นจะยังอยู่
  • −ไม่มีใครซัพพอร์ต ถ้ามีปัญหาทีมต้องแก้เอง

อ่านตารางให้ถูก

DeepFilterNet3 ไม่ได้แข่งกับอีกสามเจ้า

มันคนละหมวดกัน — ไม่ใช่ตัวเลือกที่จะเอามาแทน Krisp ได้ เพราะไม่ตัดเสียงคนพูด แต่เป็นของฟรีที่ทำให้เสียงพัดลม แอร์ คีย์บอร์ด สะอาดขึ้นกว่าที่ใช้อยู่ และทำได้เลยโดยไม่ต้องรอใคร

ท่าที่คุ้มที่สุดคือทำทั้งสองอย่าง: ลง DeepFilterNet3 สัปดาห์นี้เพื่อให้เสียงดีขึ้นทันที ระหว่างที่ฝ่ายจัดซื้อไล่ราคา Krisp อยู่ — ถ้าสุดท้ายซื้อ Krisp ก็สลับมาใช้แทนได้ ไม่เสียของ

ของฟรีตัวอื่นที่ตรวจแล้วไม่เสนอ: RNNoise (ที่ใช้อยู่), Picovoice, ตัวที่ติดมากับเบราว์เซอร์ — ทุกตัวตัดได้แต่เสียงที่ไม่ใช่เสียงคน เหมือนกันหมด

  2. ตัวที่ตัดเสียงคนอื่นได้ ใช้ในเว็บได้จริงใช่ไหม ไม่ต้องให้ user ลงโปรแกรมเพิ่ม?
  3. ใช้กับเซิร์ฟเวอร์เสียงที่เราทำเองได้ โดยไม่ต้องซื้อบริการอื่นเพิ่มใช่ไหม?
