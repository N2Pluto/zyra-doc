2Entity หลักCore entities

Entityความหมาย
Workspaceพื้นที่ทำงาน 1 ชุด มี map, member, capacity — เก็บใน tb_workspace
Mapแผนที่ 2D ใน workspace หนึ่ง — เก็บใน tb_map; workspace หนึ่งมีได้หลาย map (หลายชั้น)
Room / Room Zoneพื้นที่ย่อยบน map สูงสุด 20 ห้องต่อ map
Private ZoneRoom แบบปิด ต้อง Knock ก่อนเข้า (knock_required: true)
Zone Sectionsession ของกลุ่มคนที่กำลังใช้ zone นั้น — tb_zone_section + tb_zone_section_member
Avatarตัวละคร pixel-art ที่แทน user บน map (คนละอย่างกับรูปโปรไฟล์)
Spawn Pointจุดเกิดของ avatar เมื่อเข้า workspace ครั้งแรกหรือหลัง re-join
Office Sessionsession ของ user ที่ active บน map — เก็บใน Redis ไม่ใช่ DB
Presenceข้อมูลว่าใคร online บน map ณ ขณะนั้น (จาก WebSocket + Redis)
EntityMeaning
WorkspaceOne working area with a map, members and capacity — stored in tb_workspace
MapA 2D map inside a workspace — tb_map; a workspace can hold several (multiple floors)
Room / room zoneA sub-area of a map, max 20 per map
Private ZoneA closed room you must knock into (knock_required: true)
Zone SectionThe session of people currently using a zone — tb_zone_section + tb_zone_section_member
AvatarThe pixel-art character representing a user on the map (not the profile picture)
Spawn PointWhere an avatar appears on first entry or after re-joining
Office SessionA user's active session on the map — kept in Redis, not the DB
PresenceWho is online on the map right now (from WebSocket + Redis)

3RoleRoles

Roleสี badgeสิทธิ์
Ownerorange / amberสิทธิ์สูงสุด เชิญได้ทุก role — ออกจาก workspace ไม่ได้จนกว่าจะ Transfer Ownership
Admin / Space Adminpurpleจัดการ member ได้ แต่เชิญได้เฉพาะระดับ Member
Memberblueใช้งาน workspace ได้ ออกได้ตลอด
Pendinggrayถูกเชิญแล้วแต่ยังไม่ยืนยัน — แสดงว่า “รอยืนยัน”
role_ ใน DB—ระดับระบบ: MEMBER · ADMIN · SYSADMIN (คนละชั้นกับ role ใน workspace)
RoleBadge colourRights
Ownerorange / amberFull rights, invites any role — cannot leave until ownership is transferred
Admin / space adminpurpleManages members but can only invite at Member level
MemberblueUses the workspace; may leave at any time
PendinggrayInvited but not yet accepted — shown as "awaiting confirmation"
role_ in the DB—Platform level: MEMBER · ADMIN · SYSADMIN (a different axis from workspace role)

4Map & zoneMap & zones

คำความหมาย
Collision Layerlayer ที่กำหนด tile ที่ avatar เดินผ่านไม่ได้
Block zonezone type ที่ทำให้ tile ทั้งบริเวณเดินไม่ได้ (ไม่ใช่ object)
Barriercollision tile ที่มองไม่เห็นตรงขอบ private zone — กันเดินเข้าโดยไม่ได้รับอนุญาต
Spotlight zonezone ที่เสียงถูก broadcast ไปทั้งชั้น
Meeting zonezone ที่เข้าโหมดประชุม (video grid + chat ของ zone)
zone tileszone ที่ไม่ใช่สี่เหลี่ยม เก็บเป็น JSONB ใน tb_map_zone.tiles — ใช้ helper ใน lib/zone-utils.ts ห้ามคำนวณ AABB ดิบ
walkable_groupตัวชี้ว่า object เป็นพื้นที่เดินได้ — ใช้ตัดสิน render order ชั้นพื้น
wall_mountedobject ที่ติดผนัง — render อยู่หน้าสุดเสมอ
zIndexลำดับ render: floor < objects < avatars < UI overlay
last_positiontile ล่าสุดที่ user อยู่ ใช้เป็น spawn เมื่อกลับเข้ามา
Tiledโปรแกรมออกแบบ map ที่ export เป็น map.json
TermMeaning
Collision layerThe layer marking tiles an avatar cannot walk through
Block zoneA zone type that makes its whole area unwalkable (not an object)
BarrierInvisible collision tiles along a private zone's edge, stopping uninvited entry
Spotlight zoneA zone whose audio is broadcast to the entire floor
Meeting zoneA zone that switches you into meeting mode (video grid + zone chat)
Zone tilesNon-rectangular zones stored as JSONB in tb_map_zone.tiles — use the helpers in lib/zone-utils.ts, never raw AABB maths
walkable_groupMarks an object as walkable surface — decides floor-level render order
wall_mountedA wall-attached object — always rendered front-most
zIndexRender order: floor < objects < avatars < UI overlay
last_positionThe user's last tile, used as the spawn point when they return
TiledThe map editor used for design; exports map.json

5Movement & engineMovement & engine

คำความหมาย
zyra-enginegame engine ของ Virtual Office (PixiJS) — import จาก @/zyra-engine
WASDเดินด้วยคีย์บอร์ด W/A/S/D หรือปุ่มลูกศร
Click-to-moveคลิกบน map แล้วเดินไปตามเส้นทางที่หาให้
Sprintกด Shift ค้างเพื่อวิ่ง — ค่าความเร็วต้องตรงกันทั้ง client และ zyra-ws
Path-based movementโมเดลปัจจุบัน: move_to (ส่ง path) → server คิด duration_ms → moving → จบด้วย stop
force_syncserver สั่งให้ client เด้งกลับไปตำแหน่งจริง เมื่อ state ไม่ตรงกัน
Desyncอาการที่หน้าจอเราและ peer เห็นไม่ตรงกัน (วาร์ป, ลื่นไถล, นั่งแล้วหลุด)
AOI (Area of Interest)grid 16×16 tile ที่ใช้จำกัดการ broadcast ตำแหน่งให้เฉพาะ 3×3 cell รอบตัว
Silent Blockเดินชนสิ่งกีดขวางแล้วหยุดเฉย ๆ ไม่มี error
TILE_SIZE / PLAYER_SPEED32 px ต่อ tile · 120 px/s
TermMeaning
zyra-engineThe Virtual Office game engine (PixiJS) — imported from @/zyra-engine
WASDKeyboard walking with W/A/S/D or the arrow keys
Click-to-moveClick the map and the avatar walks the path found for it
SprintHold Shift to run — the speed constant must match on client and zyra-ws
Path-based movementThe current model: move_to (send the path) → server computes duration_ms → moving → ends with stop
force_syncThe server snapping a client back to the authoritative position when state diverges
DesyncYour screen and a peer's disagreeing (warps, sliding, sliding off a chair)
AOI (area of interest)A 16×16-tile grid limiting position broadcast to the 3×3 cells around you
Silent blockWalking into an obstacle just stops you — no error is shown
TILE_SIZE / PLAYER_SPEED32 px per tile · 120 px/s

คำชื่อใน UIความหมาย
Waveทักทายส่ง gesture ทักทาย ไม่ต้องอยู่ใกล้ — cooldown 10 วินาทีต่อคน
Followติดตามเดินตาม avatar อื่นอัตโนมัติ เก็บใน Redis เท่านั้น

Progressive Cooldown—ถูก Deny ครั้งที่ 1–2 รอ 30 วินาที, ครั้งที่ 3+ รอ 5 นาที
Spotlight broadcast—พูดออกไปทั้งชั้นจาก spotlight zone
Proximity chat—วงสนทนาที่เกิดจากการเดินเข้าใกล้กัน
Presenter guard—กฎว่าหนึ่ง zone แชร์จอพร้อมกันได้สูงสุด 2 คน
HUD—UI ที่ลอยอยู่บนแผนที่ (member panel, chat, minimap, status)
Heartbeat—สัญญาณต่ออายุ presence ใน Redis (TTL 35 วินาที)
TermUI nameMeaning
WaveWaveA greeting gesture; no proximity needed — 10s cooldown per person
FollowFollowAutomatically walking after another avatar; stored only in Redis
KnockKnockRequesting entry to a private zone — those inside press Allow / Deny
Progressive cooldown—After a deny: 30s for the 1st–2nd, 5 minutes from the 3rd on
Spotlight broadcast—Speaking to the whole floor from a spotlight zone
Proximity chat—The conversation circle formed by walking close to someone
Presenter guard—The rule capping one zone at two simultaneous screen shares
HUD—The UI floating over the map (member panel, chat, minimap, status)
Heartbeat—The signal refreshing presence TTL in Redis (35s)

9Invite & membershipInvite & membership

คำความหมาย
Invitation Tokentoken ในลิงก์เชิญที่ส่งทางอีเมล — หมดอายุ 7 วัน
Join Linkลิงก์ถาวรต่อ workspace (ต่างจาก invitation token) สร้างใหม่ได้เพื่อยกเลิกอันเก่า
Join Requestคำขอเข้าจากคนที่มาทางลิงก์ — Owner/Admin กด Approve / Reject
Pending Inviteคำเชิญที่ส่งแล้วแต่ยังไม่ถูกรับ
Auto-accept Invitetoken ถูกรับอัตโนมัติหลังสมัคร + ยืนยัน OTP หรือหลัง Google OAuth
Transfer OwnershipOwner ส่งสิทธิ์ให้ Admin คนอื่น — owner เดิมกลายเป็น Admin
Leave Confirmationต้องพิมพ์ชื่อ workspace ให้ตรง (case-sensitive) ก่อนออก
Capacityจำนวนคนสูงสุดที่ workspace รับได้ — เต็มแล้ว WS join จะถูกปฏิเสธ
1 batch = 10 emailเชิญได้สูงสุด 10 อีเมลต่อครั้ง
TermMeaning
Invitation tokenThe token in an emailed invite link — expires after 7 days
Join linkA permanent per-workspace link (unlike the invite token); regenerate it to kill the old one
Join requestA request from someone arriving via the link — Owner/Admin approves or rejects
Pending inviteAn invite that was sent but not yet accepted
Auto-accept inviteThe token is accepted automatically after signup + OTP, or after Google OAuth
Transfer ownershipThe owner hands ownership to an Admin — the old owner becomes an Admin
Leave confirmationYou must type the workspace name exactly (case-sensitive) to leave
CapacityThe workspace's people limit — once full, WS joins are refused
1 batch = 10 emailsUp to ten addresses per invite batch

10WebSocket eventWebSocket events

Eventทิศทางความหมาย
welcomeS → Cstate ทั้งหมดตอน connect (me, players[])
joined / leftS → Cมีคน join / disconnect
move_to / stopC → Sเริ่มเดินตาม path / หยุดเดิน
moving / stoppedS → Cpeer เริ่ม/จบการเดิน พร้อม duration_ms
movedS → Cอัปเดตตำแหน่งความถี่สูง — ส่งเป็น binary frame (0x01)
status / status_changedC → S / S → Cเปลี่ยน availability status
wave / wave_receivedC → S / S → Cทักทาย และ notification ถึงปลายทาง
knock / knock_decisionC → Sเคาะประตู และการตัดสิน allow/deny
room_enter / room_exitC → Sเข้า/ออกห้อง (คนละอย่างกับ media room)
section_syncทั้งสองทางsync สถานะ zone section (จำนวนคน, ล็อกหรือไม่)
capacity_reachedS → Cworkspace เต็ม — connection ถูกปิด
server_drainS → Cserver กำลังจะปิด บอกให้ reconnect ใหม่
EventDirectionMeaning
welcomeS → CFull state on connect (me, players[])
joined / leftS → CSomeone joined / disconnected
move_to / stopC → SStart walking a path / stop walking
moving / stoppedS → CA peer started or finished a walk, with duration_ms
movedS → CHigh-frequency position update — sent as a binary frame (0x01)
status / status_changedC → S / S → CAvailability status change
wave / wave_receivedC → S / S → CA wave, and the notification delivered to the target
knock / knock_decisionC → SKnocking, and the allow/deny decision
room_enter / room_exitC → SEntering/leaving a room (not the same as a media room)
section_syncboth waysSyncs zone-section state (member count, locked or not)
capacity_reachedS → CThe workspace is full — the connection is closed
server_drainS → CThe server is shutting down; reconnect after the given delay

11กฎธุรกิจที่พูดถึงบ่อยBusiness rules people quote

คำความหมาย
Office เต็มonline count ≥ capacity → เข้าไม่ได้
Max 20 roomsจำนวน room สูงสุดต่อ map
Solo Workspaceworkspace ที่มี owner คนเดียวเป็นสมาชิก
Private zone claimการจับจองโซนส่วนตัว — claim ได้ทันที และการ claim ใหม่ย้ายความเป็นเจ้าของ
Screen share max 2หนึ่ง zone แชร์จอพร้อมกันได้ 2 คน
OTPรหัส 6 หลักยืนยันการสมัคร มีเวลาหมดอายุและจำกัดจำนวนครั้ง
Login lockผิดครบจำนวนครั้ง → ล็อกชั่วคราว และล็อกนานขึ้นถ้าเกิดซ้ำ
S3 onlyไฟล์/รูปทุกอย่างเก็บบน Cloudflare R2 ไม่เก็บลง filesystem ของ API
Member API separationmember page เรียกได้แค่ /api/user/* ห้าม /api/admin/*
TermMeaning
Office fullonline count ≥ capacity → nobody else can enter
Max 20 roomsThe room limit per map
Solo workspaceA workspace whose only member is its owner
Private zone claimClaiming a private zone — instant, and a new claim transfers ownership
Screen share max 2Two simultaneous presenters per zone
OTPThe 6-digit signup code, with an expiry and an attempt limit
Login lockEnough wrong attempts locks the account temporarily, longer on repeats
S3 onlyEvery file and image lives on Cloudflare R2, never the API's filesystem
Member API separationMember pages may call /api/user/* only, never /api/admin/*
