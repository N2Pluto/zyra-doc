Vision

เป้าหมายของทีม

“ส่งมอบงานที่มี Quality ที่มีการ improve น้อยที่สุดจากคนภายนอก” Ship work at a quality bar so high that outsiders need to improve almost nothing.

Rules · 18 ข้อ

กฎการทำงาน

จัดกลุ่มจาก 18 ข้อเดิมเป็น 4 หมวด ให้เห็นภาพว่าแต่ละกฎปกป้องเรื่องอะไร

01สื่อสาร & ความรับผิดชอบ

  1. มีปัญหาอะไรให้ถาม — อย่าเดาแล้วเดินหน้าต่อ
  2. ตอบภายใน 30 นาที
  3. อยากให้ report โดยที่ไม่ต้องถาม — proactive ไม่ใช่ต้องตามทวง
  4. มีข้อ concern อะไรให้พูดก่อนถึงเวลา — ไม่ใช่พูดตอนเดดไลน์หลุดแล้ว
  5. รับผิดชอบตั้งแต่ต้นจนจบ — ไม่โยนงาน
  6. ไม่โทษตัวบุคคล → แก้ที่ระบบที่ปล่อยให้เกิดปัญหา

02คุณภาพงาน

  1. เข้าใจทุกบรรทัดก่อนส่งมอบ — อย่าเชื่อผลของ AI โดยไม่ตรวจสอบ
  2. งานต้องมี quality
  3. กำลังเสร็จ = ไม่เสร็จ
  4. Docs ดูละเอียด อ่านแล้วต้องเข้าใจ
  5. ก่อนปรับสถานะเป็น Completed ต้องเทสอย่างน้อย 80% — หมายถึงสถานะ ClickUp task ("Comp" = Completed) ไม่ใช่คำว่า Component และไม่ใช่ code coverage

03ความปลอดภัยของ Production

  1. Production มาก่อน — ปกป้องระบบที่ใช้งานจริงเสมอ
  2. งานทุกอย่างต้องผ่าน Dev → UAT → Prod
  3. Retest on prod
  4. POC ก่อนทำจริง

04กระบวนการทำงานร่วมกัน

  1. ปรับอะไรให้แจ้งกลาง chat กลุ่มหรือ Meeting
  2. ถ้าพัก ให้เปลี่ยนสถานะเป็น "พัก"
  3. กฎสามารถเพิ่มได้ตลอด
